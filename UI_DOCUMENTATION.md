# Документация UI главного экрана

## Обзор

Главный экран приложения "Карта здоровья ребёнка" реализован с использованием современных UI/UX практик и плавных анимаций. Все переходы между экранами выполнены с анимацией длительностью 200-300мс.

## Структура главного экрана

### 1. Верхняя панель профиля ребёнка

**Расположение:** `lib/presentation/widgets/child_profile_header.dart`

**Компоненты:**
- **Аватар с Hero анимацией** (72x72px)
  - Круглая форма с градиентом
  - Поддержка изображений или плейсхолдера с инициалами
  - Hero tag: `child_avatar_{childId}`
  - Анимация тени при наведении

- **Основная информация:**
  - Имя ребёнка (жирный шрифт, headline small)
  - Возраст (автоматический расчёт с корректным склонением)
  - Дата рождения (формат dd.MM.yyyy)

- **Медицинские индикаторы (чипы):**
  - Группа крови (красный цвет, иконка bloodtype)
  - Количество аллергий (оранжевый цвет, иконка warning)
  - Количество хронических заболеваний (синий цвет, иконка hospital)

**Анимации:**
- AnimatedContainer с длительностью 250мс
- Hero transition при переходе к профилю
- Плавное появление чипов (200мс)

---

### 2. Горизонтальная лента эпизодов болезней

**Расположение:** `lib/presentation/widgets/episodes_carousel.dart`

**Дизайн:**
- Высота: 140px
- Горизонтальный скролл
- Отступы между карточками: 12px

**Карточка эпизода:**
- Размер: 160x140px
- Цветовая схема:
  - **Активные эпизоды:** красный фон (red.shade50), красная граница (red.shade400)
  - **Закрытые эпизоды:** зелёный фон (green.shade50), зелёная граница (green.shade400)

**Содержимое карточки:**
1. Индикатор статуса (вверху слева)
2. Иконка статуса (вверху справа)
3. Диагноз (titleMedium, жирный, максимум 2 строки)
4. Дата начала (bodySmall с иконкой календаря)
5. Длительность (bodySmall с иконкой часов)

**Анимации:**
- ScaleAnimation при нажатии (0.95 scale)
- Hero transition с тегом `episode_card_{episodeId}`
- AnimatedContainer для цветовых изменений (250мс)

**Состояние "Нет эпизодов":**
- Иконка сердца (48px)
- Текст "Нет эпизодов болезней"
- Светлый фон с обводкой

---

### 3. Календарь месяца

**Расположение:** `lib/presentation/widgets/health_calendar.dart`

**Библиотека:** table_calendar ^3.0.9

**Возможности:**
- Свайп между месяцами
- Отображение событий (эпизоды, визиты, госпитализации)
- Локализация для RU/UZ/EN
- Выделение текущего дня

**Дизайн:**
- Скруглённые углы: 20px
- Тень: blurRadius 10, offset (0, 4)
- Белый фон (theme.colorScheme.surface)

**Заголовок:**
- Месяц и год (titleLarge, жирный, капитализированный)
- Кнопки навигации (стрелки влево/вправо)

**Маркеры событий:**
- До 3 точек под датой
- Цвет: theme.colorScheme.secondary
- Размер: 6x6px, круглые

**Стили дней:**
- Выбранный: primary цвет, круглый
- Сегодня: primary цвет с opacity 0.3
- Выходные: error цвет (красный текст)

**Анимации:**
- FadeTransition при загрузке (300мс)
- Плавная смена месяца

---

### 4. Статистика за год

**Расположение:** `lib/presentation/widgets/yearly_statistics.dart`

**Библиотека:** fl_chart ^0.66.0

**Компоненты:**

#### 4.1. Заголовок с выбором года
- Текст "Статистика" (titleLarge, жирный)
- Навигация по годам (стрелки + текущий год)

#### 4.2. Основные метрики (2 карточки)
**Карточка "Эпизодов":**
- Иконка: Icons.sick (синий цвет)
- Значение: количество эпизодов
- Фон: синий с opacity 0.1

**Карточка "Средняя длительность":**
- Иконка: Icons.timelapse (оранжевый цвет)
- Значение: среднее количество дней
- Фон: оранжевый с opacity 0.1

#### 4.3. Круговая диаграмма топ-диагнозов
- Максимум 5 диагнозов
- Цвета: красный, оранжевый, янтарный, зелёный, синий
- Центральное отверстие: 40px
- Анимация при касании (увеличение сектора)

**Легенда:**
- Цветные круги (12x12px)
- Названия диагнозов (bodySmall)
- Максимум 2 строки на диагноз

**Состояние "Нет данных":**
- Иконка bar_chart (64px)
- Текст "Нет статистики за {год} год"

**Анимации:**
- FadeTransition при загрузке (300мс)
- Интерактивность диаграммы (увеличение при касании)

### 5. Нижняя навигация

**Расположение:** `lib/presentation/screens/home_screen.dart` (метод `_buildBottomNavigationBar`)

**Анимация выбранной кнопки:**
- Фоновый цвет: primary с opacity 0.1
- Цвет иконки: primary
- Жирный текст
- Длительность: 250мс

## Экран деталей эпизода

**Расположение:** `lib/presentation/screens/episode_detail_screen.dart`

### Компоненты:

#### 1. SliverAppBar с Hero
- Высота: 200px
- Gradient фон (активный - красный, закрытый - зелёный)
- Hero tag совпадает с карточкой: `episode_card_{episodeId}`
- Индикатор статуса в виде чипа

#### 2. Секция основной информации
- Дата начала
- Дата окончания (если есть)
- Длительность в днях
- Скруглённая карточка с тенью

#### 3. Секция цепочки эпизодов
- Вертикальный список с номерами
- Стрелки вниз между эпизодами
- Выделение текущего эпизода

#### 4. Секция заметок
- Текстовое поле с обводкой
- Показывается только если есть заметки

#### 5. Секция назначений
- Список препаратов
- Иконка medication
- Доза и график приёма

### Анимации:
- FadeTransition для контента (300мс)
- SlideTransition снизу вверх (offset 0.3 → 0)
- Плавный переход от списка эпизодов (Hero)

## Анимации (Сводка)

### Длительности:
- **200мс:** Мелкие элементы (кнопки, чипы)
- **250мс:** Средние компоненты (карточки, контейнеры)
- **300мс:** Крупные переходы (экраны, Hero)

### Типы анимаций:
1. **Hero transitions** - для карточек эпизодов и аватаров
2. **ScaleAnimation** - для нажатий на кнопки
3. **FadeTransition** - для появления контента
4. **SlideTransition** - для списков и панелей
5. **AnimatedContainer** - для изменения стилей

### Кривые (Curves):
- `easeInOut` - основная для большинства анимаций
- `easeIn` - для fade transitions
- `easeOut` - для slide transitions

## State Management

**Provider:** HomeProvider (`lib/presentation/providers/home_provider.dart`)

**Управляемое состояние:**
- Выбранный ребёнок
- Список всех детей
- Эпизоды болезней
- Текущий месяц календаря
- Выбранный год для статистики
- События календаря
- Состояние загрузки

**Методы:**
- `selectChild(childId)` - выбрать ребёнка
- `changeFocusedMonth(month)` - изменить месяц календаря
- `changeSelectedYear(year)` - изменить год статистики
- `refresh()` - обновить все данные
- `getEventsForDay(day)` - получить события для дня

## Локализация

**Поддерживаемые языки:**
- Русский (ru_RU) - по умолчанию
- Узбекский (uz_UZ)
- Английский (en_US)

**Форматы дат:**
- dd.MM.yyyy - краткий формат
- dd.MM.yy - для карточек

**Склонения:**
- Годы: год/года/лет
- Месяцы: месяц/месяца/месяцев

## Производительность

### Оптимизации:
1. **ListView.builder** для списков эпизодов
2. **CustomScrollView** с Slivers для главного экрана
3. **RefreshIndicator** для обновления данных
4. **const конструкторы** где возможно
5. **AnimationController dispose** во всех виджетах

### Кэширование:
- Drift автоматически кэширует запросы
- Provider сохраняет состояние между перестройками
- Календарь загружает только текущий месяц

---

## Адаптивность

### Ориентация:
- Поддержка только портретной ориентации

### Безопасные зоны:
- SafeArea используется для верхней и нижней панелей
- ViewInsets учитываются для модальных окон

### Скролл:
- BouncingScrollPhysics для iOS-подобного эффекта
- RefreshIndicator для pull-to-refresh
