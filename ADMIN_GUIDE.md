## Введение

Админ-панель предоставляет расширенные возможности для управления данными приложения:

- ✅ Просмотр и управление всеми детьми
- ✅ Управление эпизодами болезней
- ✅ Просмотр логов активности
- ✅ Управление пользовательскими профилями
- ✅ Статистика и аналитика
- ✅ Безопасность с паролем администратора

## Вход в админку

### Доступ к админке

1. **Через меню настроек**:
   - Откройте настройки приложения
   - Нажмите на скрытую кнопку "Админка" (10 раз tap на версию)

2. **Прямой URL**:
   - Навигация: `/admin/login`

### Авторизация

**Пароль по умолчанию**: `0000`

```
┌─────────────────────────────┐
│   🔐 Вход в админку         │
│                             │
│   Пароль: [____]            │
│                             │
│   [Войти]                   │
└─────────────────────────────┘
```

⚠️ **ВАЖНО**: Смените пароль по умолчанию после первого входа!

## Управление данными

### Управление детьми

**Путь**: `/admin/children`

#### Функции:
- ✅ Просмотр всех профилей детей
- ✅ Поиск по имени
- ✅ Удаление профиля ребенка
- ✅ Удаление со всеми связанными данными

#### Как удалить ребенка:

1. Откройте "Управление детьми"
2. Найдите нужного ребенка
3. Нажмите меню (⋮) → "Удалить"
4. Подтвердите удаление

⚠️ **ПРЕДУПРЕЖДЕНИЕ**: Удаление ребенка удаляет:
- Все эпизоды болезней
- Все назначения и приемы
- Все анализы и процедуры
- Все прикрепленные файлы

### Управление эпизодами

**Путь**: `/admin/episodes`

#### Функции:
- ✅ Просмотр всех эпизодов болезней
- ✅ Фильтрация по статусу
- ✅ Просмотр деталей эпизода
- ✅ Удаление эпизода

#### Статусы эпизодов:
- `active` - Активный
- `recovered` - Выздоровел
- `chronic` - Хронический

### Управление пользователями

**Путь**: `/admin/users`

Управление профилями пользователей (до 5 профилей на устройство).

## Логи активности

**Путь**: `/admin/logs`

### Возможности

#### Просмотр логов
- Все действия администратора
- Дата и время действия
- Тип изменения
- Измененная сущность

#### Типы действий
- `create` - Создание ➕
- `update` - Обновление ✏️
- `delete` - Удаление 🗑️
- `login` - Вход 🔑
- `logout` - Выход 🚪
- `export` - Экспорт 📤
- `backup` - Резервная копия 💾

#### Поиск и фильтрация
- Поиск по тексту
- Фильтр по действию
- Фильтр по дате
- Фильтр по администратору

#### Экспорт логов

Логи можно экспортировать в:
- **JSON**: Полная структура данных
- **CSV**: Табличный формат для Excel

#### Очистка логов

- **Очистить старые** - Удаляет логи старше 90 дней
- **Очистить все** - Удаляет все логи (необратимо!)

## Настройки админки

**Путь**: `/admin/settings`

### Персонализация

#### Имя администратора
Измените имя, которое отображается в логах:
```
Администратор → Иван Иванов
```

### Безопасность

#### Смена пароля

1. Откройте настройки админки
2. Выберите "Сменить пароль"
3. Введите старый пароль
4. Введите новый пароль (мин. 4 символа)
5. Подтвердите новый пароль

#### Сброс пароля

Если забыли пароль:
1. Настройки админки → "Сбросить пароль"
2. Пароль вернется к `0000`

⚠️ **ВНИМАНИЕ**: Сброс пароля требует подтверждения!

---

## Безопасность

### Рекомендации

#### 1. Пароль администратора

✅ **Делайте**:
- Используйте уникальный пароль
- Длина минимум 8 символов
- Сочетание цифр и букв
- Меняйте пароль регулярно

❌ **Не делайте**:
- Не используйте `0000`, `1234`, `password`
- Не делитесь паролем
- Не храните пароль в открытом виде

#### 2. Логи активности

- Регулярно проверяйте логи
- Ищите подозрительную активность
- Проверяйте время входов

#### 3. Автоматический выход

Сессия админа действительна **24 часа**.
После этого требуется повторная авторизация.

### Восстановление доступа

Если утерян пароль:
1. Удалите приложение
2. Установите заново
3. Пароль сбросится на `0000`

⚠️ **ВНИМАНИЕ**: Все данные и настройки сохранятся!

## Архитектура

### Структура файлов

```
lib/presentation/
├── screens/admin/
│   ├── admin_dashboard_screen.dart       # Панель администратора
│   ├── admin_login_screen.dart           # Экран входа
│   ├── admin_children_screen.dart        # Управление детьми
│   ├── admin_episodes_screen.dart        # Управление эпизодами
│   ├── admin_users_screen.dart           # Управление пользователями
│   ├── admin_settings_screen.dart        # Настройки админки
│   ├── admin_logs_screen.dart            # Логи активности
│   └── widgets/
│       ├── admin_drawer.dart             # Боковое меню
│       └── admin_stat_card.dart          # Карточка статистики
│
├── providers/
│   ├── admin_auth_provider.dart          # Авторизация админа
│   ├── admin_provider.dart               # Управление данными
│   └── admin_logs_provider.dart          # Управление логами
│
├── data/models/
│   └── activity_log.dart                 # Модель лога активности
│
└── routes/
    └── app_router.dart                   # Маршруты (обновлен)
```

### Провайдеры

#### AdminAuthProvider
- Авторизация администратора
- Хранение пароля в FlutterSecureStorage
- Управление сессией

#### AdminProvider
- CRUD операции для всех сущностей
- Статистика
- Интеграция с логами

#### AdminLogsProvider
- Создание логов активности
- Фильтрация и поиск
- Экспорт логов

### Хранилище данных

#### FlutterSecureStorage
- Пароль администратора
- Зашифровано на уровне ОС

#### SharedPreferences
- Логи активности (JSON)
- Имя администратора
- Время последнего входа

## FAQ

### Как войти в админку?

URL: `/admin/login`, пароль по умолчанию: `0000`

### Как изменить пароль?

Настройки админки → Сменить пароль

### Как очистить логи?

Логи активности → Меню (⋮) → Очистить старые/все логи

### Как экспортировать данные?

Логи активности → Кнопка "Экспорт" → Выбрать формат

### Можно ли восстановить удаленные данные?

Нет, удаление необратимо. Используйте резервное копирование!

### Безопасно ли хранится пароль?

Да, пароль хранится в FlutterSecureStorage с шифрованием.

### Как долго действует сессия?

24 часа с момента входа.
